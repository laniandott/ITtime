① 信息架构：9 页 → 5 页

按「你一天实际怎么用」重新分组，功能一项不少，只是不再让同一件事散在多个页面：

  • 工作台 = 打卡页（计时 + 快速开始）+ 今日概览 + 最近时间线 + 今日待办。打开应用第一眼就是它，正在计时永远在最上面。
  • 时间 = 日历 + 计划合并。周条切换日期，下方「计划｜实际」双列共用分钟刻度——原来的两个页面本来就在看同一天，没必要分开。
  • 事项 = 待办 + 习惯目标合并。它们本来就是「要做的事」的两种形态，一条流 + 一个目标卡组。
  • 洞察 = 统计页。趋势、结构、排行、计划遵循四块拼成一个 bento。
  • 体系 = 标签 + 分类 + 设置入口。低频操作全部收进左栏底部。

② 视觉语言：Aurora Glass

从「亮色后台管理系统」切换到「深空玻璃」——深底、玻璃拟态卡片、极光环境光、渐变只出现在「活的东西」上（计时环、主按钮、增长数字）：

Deep Space#070b14 底色
Glass白 6% + 模糊 20
Aurorateal → cyan 渐变
Nebulaviolet → cyan
Ink#e8eef6 主文字
  • 颜色规则不变：标签色仍然只是一个 6px 色点；渐变只给计时环 / 主按钮 / 关键数字；红只给危险。
  • 发光是有语义的：计时环的光晕 = 「正在进行」，导航选中态的微光 = 「你在这里」。其余地方一律不发光。
  • 动效克制：页面淡入 350ms、卡片悬浮上浮 2px、计时数字呼吸。没有弹跳、没有转场特效。

③ 落地方式

  • 现有代码保留 local-first 架构与全部业务逻辑，只换 Layout / 各页面容器 的壳和 index.css 的 token 层。
  • 暗色成为默认主题（现有 light 主题保留为可选项）。
  • 预计改动：Layout.tsx、9 个页面的容器结构、index.css 重写 token 段。业务组件（弹窗、表单逻辑）不动。
